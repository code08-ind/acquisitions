# Docker Quick Reference

## Development Commands

```bash
# Start development environment
docker-compose -f docker-compose.dev.yml --env-file .env.development up

# Start in background
docker-compose -f docker-compose.dev.yml --env-file .env.development up -d

# Rebuild and start
docker-compose -f docker-compose.dev.yml --env-file .env.development up --build

# Stop services
docker-compose -f docker-compose.dev.yml down

# View logs
docker-compose -f docker-compose.dev.yml logs -f

# Execute commands in container
docker-compose -f docker-compose.dev.yml exec app npm run db:migrate
docker-compose -f docker-compose.dev.yml exec app npm run lint
docker-compose -f docker-compose.dev.yml exec app sh

# Restart application only
docker-compose -f docker-compose.dev.yml restart app
```

## Production Commands

```bash
# Start production environment
docker-compose -f docker-compose.prod.yml --env-file .env.production up -d

# Rebuild and start
docker-compose -f docker-compose.prod.yml --env-file .env.production up -d --build

# Stop production
docker-compose -f docker-compose.prod.yml down

# View logs
docker-compose -f docker-compose.prod.yml logs -f app

# Run migrations
docker-compose -f docker-compose.prod.yml exec app npm run db:migrate

# Monitor resources
docker stats acquisitions-app-prod
```

## Cleanup Commands

```bash
# Remove all containers and volumes
docker-compose -f docker-compose.dev.yml down -v

# Remove unused images
docker image prune -a

# Full cleanup
docker system prune -a --volumes
```

## Debugging

```bash
# Check running containers
docker ps

# Inspect container
docker inspect acquisitions-app-dev

# Check logs of specific service
docker-compose -f docker-compose.dev.yml logs db
docker-compose -f docker-compose.dev.yml logs app

# Enter container shell
docker exec -it acquisitions-app-dev sh

# Check environment variables
docker-compose -f docker-compose.dev.yml exec app env | grep DATABASE
```
